# SQL Analytics Pack

Short, end-to-end SQL coursework project focused on real business questions using an orders + accounts dataset. The work moves from fundamentals to advanced analysis, with each phase answering concrete risks and performance questions.

## What I learned
- Core SQL querying: `SELECT`, `WHERE`, `ORDER BY`, `LIMIT`, and derived columns
- Filtering logic: `AND/OR/NOT`, `IN`, `BETWEEN`, `LIKE`, and NULL handling
- Joins: inner, left/right, full, and self joins
- Aggregations: `COUNT`, `SUM`, `AVG`, `MIN`, `MAX`, `GROUP BY`, `HAVING`
- Subqueries and CTEs for multi-step analysis
- Data cleaning with string functions and standardization rules
- Window functions for ranking, trends, and percentiles
- Translating business questions into measurable SQL outputs

## What I did
Each phase is a self-contained SQL workbook that answers a set of business questions.
